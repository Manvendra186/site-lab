## Fixes applied this session

1. **`packages/shared/src/form.tsx`** — latent RHF type error surfaced only because H1 consumes the form kit.
   Typed `useFormKit` as `z.infer<T> & FieldValues`, imported `Resolver`/`DefaultValues` from
   `react-hook-form`, and cast the zod resolver + default values to satisfy `useForm`.
   (Index app unaffected — it does not import `@site-lab/shared`.)
2. **`apps/h1-quiet-luxury/src/app/layout.tsx`** — typed `children` as `ReactNode` (was missing `LayoutProps`).
3. **`apps/h1-quiet-luxury/src/components/navigation/header.tsx`** — removed `setOpen(false)` from a
   `pathname`-keyed `useEffect` (lint: `react-hooks/set-state-in-effect`); mobile menu now closes on link
   click via `onClick={() => setOpen(false)}`.
4. **`gallery/page.tsx`** — image `ratio={4 / 3}` (was inconsistent).
5. **`contact/page.tsx`** — uses centralized `CONTACT` fields + group data (no hard-coded copy).
6. **`footer.tsx`** — uses `CONTACT.demoNote` (single source for the demo disclaimer).
7. Cleared stale `.next` artifacts before the final build.
