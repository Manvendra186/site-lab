## Implementation notes (built 2026-09-19)

1. **`await params` from the start** — the single dynamic route (`rooms/[slug]/page.tsx`) types
   `params: Promise<{ slug: string }>` and `await params` in both `generateMetadata` and the page
   component (decision #18). This avoids the H2 dev-only bug where a synchronous `params.slug` read
   404'd every dynamic route under Playwright while the SSG build still passed.
2. **Identity kept distinct** — dark-first charcoal/silver/tungsten palette, Bebas Neue + Space
   Grotesk, the "flicker" (one-shot opacity flicker) + "fade" (opacity 0→1, no translate) motion,
   and the sprocket-hole leader + timecode-label motif. Deliberately avoids H1's hairline rules,
   H2's dotted-leader/specimen motif, and H3's diamond ornament + numbered lineage (brief §Do-not-use).
3. **Shared primitives only** — `Container`, `Img`, `Reveal`/`useInView`/`usePrefersReducedMotion`,
   the form kit (RHF + zod), and the SEO/JSON-LD helpers from `@site-lab/shared`; no visual language
   leaks in from the shared package.
4. **Dark-first, the one site in the set that lives at night** — `color-scheme: dark`, charcoal
   background, silver body text, a single warm tungsten accent. The hero carries the flicker; the
   text sits above it on the charcoal ground so it is always readable.
5. **Demo-only reservation** — the reserve form validates client-side (RHF + zod) and reaches a
   success state; nothing is sent or stored (Bible §10). No fake reviews, awards, badges, gradients,
   or glassmorphism.

**Minor, acceptable echoes:**
- **H3 (gold `#B0854A`) and H4 (tungsten `#d8b25a`) both use a warm gold/amber accent.** H3 is
  light-first (ivory ground, brown-gold) and H4 is dark-first (charcoal ground, yellow-amber). The
  ground is the differentiator — the two sites read as day vs night, not "same template, different
  colors."
- **H4's room-card index badge (01, 02, …)** is a small numbered marker, not a signature motif. H2's
  specimen numbers and H3's numbered lineage are full identity systems; H4's is a quiet list index.
  H4's signature motif is the sprocket-hole leader + timecode.
- **H2/H3/H4 all target `/reserve`** as the primary CTA. This is a conventional path, not a lifted
  asset or layout.

**Verdict:** H4 is clearly distinct from H1, H2 and H3 on palette (dark-first), type, motion, motif,
city, room concept, and voice. No re-art-direction required.
