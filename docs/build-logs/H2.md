## Fixes applied this session

1. **Dynamic route pages** (`stays/[slug]/page.tsx`, `field-notes/[slug]/page.tsx`) — Next.js 16 makes
   `params` a **Promise**. Both `generateMetadata` and the page component now type it as
   `params: Promise<{ slug: string }>` and `await params` before reading `slug`. Previously they read
   `params.slug` synchronously, which threw during dev SSR and 404'd every dynamic route under Playwright
   (the SSG build still passed because `generateStaticParams` supplies the params at prerender time).
   Matches the H1 pattern.
2. **Page/data reconciliation** — pages now read the real data shapes instead of a missing/renamed export:
   The Forest → `FOREST.layers` + `FOREST.principles`; Days → `DAYS.hours`; The Table → `TABLE.body` +
   `TABLE.menu`; Stays index no longer depends on a missing `STAYS` export (uses `ROOMS`); Reserve →
   `RESERVE.details` / `RESERVE.reach` / `RESERVE.demoNote`; Footer → valid `RESERVE` data + image credits.
3. **`e2e/home.spec.ts`** — removed an unused `page` destructure in the mobile-reserve-bar test (lint warning).

**Minor, acceptable echo:** H1 journal titles and H2 field-note titles independently use generic editorial
patterns — "what the [element] does at [time]" (H1 *what-the-lake-does-at-six* / H2 *what-the-mist-does-at-five-thirty*),
"a note on [X]" (H1 *a-note-on-linen* / H2 *a-note-on-ferns*), and a "staying…" opener (H1 *staying-longer* /
H2 *staying-in-the-shade*). These are natural, independent title choices with different content and niche —
not lifted assets or layouts. They do not make the two sites read as "same template, different colors."

**Verdict:** H1 and H2 are clearly distinct on palette, type, motion, motif, city, room concept, and voice.
No re-art-direction required.
